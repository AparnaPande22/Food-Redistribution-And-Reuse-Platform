Developed **Beyond Waste**, a full-stack Food Redistribution and Reuse Platform using **React, Spring Boot, MySQL, and a .NET-based Payment Microservice** to connect food donors, receivers, volunteers, and administrators. Built secure RESTful APIs for user authentication, food donations, request management, volunteer assignment, delivery tracking, payment processing, and dashboard analytics. Implemented **JWT-based authentication** and **role-based access control** to ensure secure access across the platform. Designed a scalable relational database and adopted a layered architecture with a dedicated Payment Microservice to build a reliable, maintainable, and efficient food redistribution system.
